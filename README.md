# Captcha-maker

reCAPTCHA 형태의 이미지 포스터 제작기.

- 3×3 이미지(일괄 업로드 · 개별 크롭 · 드래그로 순서 변경)
- 헤더 안내 문구 / 제목 / 카드 아래 문구: 폰트(Sans · Pretendard · Typewriter · Roboto), 크기, 자간, 행간, 굵기, 색, 정렬
- 뒤쪽 “I’m not a robot” 바 표시 전환
- 배경 단색 또는 이미지, 캔버스 9:16 · 4:5 · 1:1 · 직접 입력
- 캡챠 크기 · 위치 조절(드래그, X/Y, 중앙 정렬)
- PNG 저장: 설정한 출력 크기 그대로(기기 픽셀 배율과 무관), 미리보기와 같은 렌더러 사용
